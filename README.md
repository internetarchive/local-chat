# Local Chat

`<local-chat>` is a floating, resizable chat widget powered entirely by
Chrome's built-in on-device AI, grounded in context you provide.

## Status

Early scaffolding. The actual design (Element API, attributes, events,
streaming/markdown behavior) hasn't been written yet — see this repo's
issue tracker for progress.

## Development

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
```
